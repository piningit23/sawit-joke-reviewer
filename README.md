A one-line joke about working beside an AI coding agent: the agent has picked up its human's worst habits — it leaves TODOs everywhere and blames the previous developer, only for the punchline to land on the person reading the diff. The joke is written by a small deterministic Python program (stdlib only, no network) so the entry is exactly the same on every run.

## Run

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (creating `/output` if needed).
